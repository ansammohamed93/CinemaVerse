Clone/Download repo\n2. Open `index.html` in any browser\n\n```bash\nstart index.html\n```\n\n## Deployment\nGitHub Pages: Settings > Pages > Deploy from 'main' branch\n\nLive demo: https://ansammohamed93.github.io/CinemaVerse/\n\nEnjoy! 🎥
